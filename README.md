# Examezy landing (examezy.com)

Marketing site for **Examezy**: the Vacademy exams & assessments product (online, paper and proctored exams; auto,
on-screen and AI evaluation; results and analytics), sold under its own brand.
Static Next.js 15 + Tailwind 4 export, the same stack as evalezy.com, telleo.ai and tutezy.ai.

## Run

    pnpm install
    pnpm dev          # http://localhost:3000
    pnpm build        # static export in ./out (+ out/llms-full.txt)
    pnpm typecheck

## Deploy (Cloudflare Pages)

The Pages project is **`examezy`** on the Vidyayatan Cloudflare account, created by direct upload:

    pnpm build
    cd /tmp && pnpm dlx wrangler@4 pages deploy /path/to/examezy_landing_page/out --project-name examezy --branch main

Live at https://examezy.pages.dev. Custom domains `examezy.com` and `www.examezy.com` are attached to the project but
need DNS: Workers & Pages → `examezy` → Custom domains → **Activate domain** on each (Cloudflare adds the proxied
CNAME to `examezy.pages.dev`), or add those two CNAME records in DNS yourself. Wrangler's OAuth login has no DNS
permission, so this step can't be scripted from here.

Run `wrangler pages deploy` from **outside** the repo (or with an explicit `out` path from another directory): from
inside it, wrangler 4.15x detects Next.js and rewrites package.json, next.config.ts and the lockfile for OpenNext
Workers (it happened once on 15 Oct 2026 and was reverted). To deploy on every push instead,
create a Git-connected Pages project in the dashboard (Framework preset **Next.js (Static HTML Export)**, build
`pnpm build`, output `out`, env `NODE_VERSION=20`) and move the domains to it (a direct-upload project can't be
switched to Git later).

After the first deploy: submit `https://examezy.com/sitemap.xml` in Google Search Console and Bing Webmaster Tools, and
check that Cloudflare → Security → Bots → "Block AI bots" is **off** (robots.txt welcomes AI crawlers on purpose).

## The truth file

`docs/PRODUCT_FACTS.md` lists every claim the site may make, from a code-verified inventory of `vacademy_platform`
(15 Oct 2026), plus a **NEVER claim** list (OMR, match-the-following, lockdown browser, paid tests, certificates,

## Brand

- Colours: ink `#0A1024`, cobalt `#2B50FF` (text-safe `#1A34B8`), marigold `#FFB31A` (the filled answer bubble),
  paper `#F6F7FB`.
- Type: Space Grotesk (display), Inter (body), JetBrains Mono (code). All self-hosted in `src/fonts/`.
- Motif: OMR answer bubbles (empty rings, one filled in marigold). Logo: four bubbles on an ink tile, one filled
  with a tick.

## Leads

The form posts from the browser to the Vacademy CRM audience `e2be8dd5-5d32-473d-b4ec-0d2491bcc69c`
(`/admin-core-service/open/v1/audience/lead/submit`, CORS allows any origin). Fields: full name, email, phone,
designation (role), institute name, and **Details** (`88c95bb2…`), one line with what they want to run, candidates per
exam, which form (`home`, `demo-page`, `pricing`, `for/<slug>`), UTM source and their message.
The CRM de-duplicates per audience; a repeat visitor sees "Welcome back".

## Before launch (owner to-dos)

1. **Mailbox.** `hello@examezy.com` is shown sitewide. Create it (Cloudflare Email Routing works) or change `SALES_EMAIL`.
2. **Booking link.** Set `BOOKING_URL` in `src/lib/site.ts` (empty = every "Book a demo" goes to `/demo/`).
3. **Login link.** "Log in" points to `https://dash.vacademy.io/`. Confirm.
4. **Pricing.** The site publishes no prices: plans are quoted by candidates and exam calendar, AI checking per copy.
   It promises a **pilot exam with one batch** (same promise as vacademy.io/features/assessments). Confirm.
5. **Analytics.** The site loads the shared GTM container `GTM-5C4DDJ6W`, which also fires the Vacademy Google Ads
   conversion and Meta tags on examezy.com (a form test from localhost fired the Ads `conversion` event). Add an
   examezy.com hostname condition in GTM or use a separate container. dataLayer events: `demo_request`, `book_demo`,
   `whatsapp`, `playground_submit`.
6. **Lead email.** Only the CRM receives leads. For an instant email alert, add an `examezy` brand + route to the shared
   `vacademy-send-email` Worker and post to it from `leadSubmit.ts`, as tutezy.ai does.
7. **Reply promise.** Forms say "We usually reply within one working day". Make sure someone owns the audience.
8. **Product bugs to fix before advertising them** (found while auditing, see `docs/PRODUCT_FACTS.md`): partial marking
   on multiple-correct MCQs is discounted twice; numeric negative marking is scaled down; the admin "increase time"
   dialog is a placeholder; approving a learner's extra-time request adds no time; reattempt limits aren't enforced.
   The site doesn't claim any of these.
9. **www.** `www.examezy.com` serves the same site; canonical tags point to `https://examezy.com`. Add a 301 redirect
   rule (Rules → Redirect) if you want it to redirect instead.
